# Independent research replay: permission route and draft template

The repository remains proprietary. The owner's authorization for this experiment is not an authorization for arbitrary third-party execution or redistribution. This document provides a concrete route to request and record case-by-case permission; it does not itself grant rights or amend [LICENSE](../LICENSE).

An evaluator should open a repository issue requesting permission (or contact the repository owner through an existing agreed channel), naming their organization, intended evaluator(s), experiment scope, exact revision, execution environment, access period and proposed outputs. The rights holder must supply a separate written acceptance identifying the permitted parties and activities. Record that acceptance with the evaluator's experiment materials; do not publish personal details or confidential correspondence without agreement. No request was sent and no outside evaluator grant is represented as completed here.

The lowest-compute option is archived-byte evaluation using `research/paired_cross_system_v1/README.md`; it needs the repository evaluator and pinned mido but no generator execution. A generation replication additionally needs pinned Constraint Music/OR-Tools, music21, Diatony/Gecode and their dependencies. External projects have their own licenses; a Constraint Music grant cannot replace their terms.

## Request text for an evaluator to complete

> I request written permission for [named evaluator(s), organization] to inspect and execute Constraint Music revision [commit/tree] for [archived evidence replay / new generation replication / both] of the paired cross-system conformance study. Execution will occur in [environment/location] during [dates], with access limited to [people]. We propose to publish [aggregate tables, discrepancy descriptions, permitted generated outputs], retaining provenance and distinguishing our replication from the original collection. We request clarification on any limits to copying, retention and publication. We will not assume permission from public repository access or this request.

This draft is an operational starting point, not an issued license. The owner can revise its terms for a particular evaluator. Outside replication, any public research-run license, and publication of an independently signed grant remain owner/evaluator actions after this implementation.
